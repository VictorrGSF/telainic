# 📅 Sistema de Agendamento de Consultas SUS

Projeto desenvolvido em Android Studio utilizando Kotlin e XML, simulando um sistema de agendamento de consultas inspirado na identidade visual do SUS.

## 📋 Funcionalidades

### Tela Inicial
- Exibe uma tela de boas-vindas.
- Possui botão para iniciar o processo de cadastro.

### Tela de Cadastro
- Campo para preenchimento do nome do usuário.
- Campo para preenchimento do e-mail.
- Validação básica dos dados informados.
- Exibição de mensagem de confirmação após o cadastro.

### Tela de Agendamento
- Exibe saudação personalizada com o nome do usuário.
- Exibe mensagem informando que os dados foram carregados com sucesso.
- Seleção da especialidade médica através de menu suspenso (Spinner).
- Seleção da unidade de saúde.
- Seleção da data da consulta.
- Seleção do período desejado.
- Campo para descrição do motivo da consulta.

## 🛠️ Tecnologias Utilizadas

- Kotlin
- Android Studio
- XML
- ConstraintLayout
- CardView
- Intent para navegação entre telas

## 🎨 Interface

A interface foi inspirada nas cores e identidade visual do Sistema Único de Saúde (SUS), utilizando:

- Azul SUS (#0057B8)
- Branco para textos principais
- Tons claros para informações secundárias
- Componentes organizados para facilitar a usabilidade

## 🔄 Fluxo da Aplicação

```text
Tela Inicial
      ↓
Tela de Cadastro
      ↓
Confirmação do Cadastro
      ↓
Tela de Agendamento
```

## 🚀 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar:

- Desenvolvimento Android nativo
- Navegação entre Activities
- Manipulação de componentes visuais
- Captura e exibição de dados do usuário
- Construção de interfaces responsivas utilizando ConstraintLayout
- Boas práticas de organização de código
